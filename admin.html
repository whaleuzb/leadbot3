Telegram bot…

Yangi arizalar shu bot orqali Telegramga keladi.

    Qanday sozlanadi?
    1. Telegramda @BotFather ga yozing → /newbot → bot yarating va tokenni oling.
    2. Botingizni Telegramda oching va /start yozing (yoki guruhga qo‘shib, guruhda xabar yozing). Bot javob bermaydi — bu normal.
    3. Yuqoridagi “Chat ID topish” tugmasini bosing, ro‘yxatdan chatingizni “Shuni tanlash” bilan tanlang.
    4. Railway → web servisi → Variables ga TELEGRAM_BOT_TOKEN ni qo‘shing (chat ID ni panel o‘zi saqlaydi).
    Sotib olish tugmalari shu akkauntga yo‘naltiradi.
